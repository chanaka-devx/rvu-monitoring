# crediting module

Generated by `pnpm gen:module crediting`.

## Layout

- `domain/` - framework-free domain types and rules.
- `application/` - use cases. May import only this module's domain/application and the shared kernel.
- `infrastructure/` - adapters for databases, messaging and external systems.
- `interface/` - inbound adapters such as HTTP controllers.
- `crediting.module.ts` - the NestJS wiring file. It may import any layer of this module.
- `public-api.ts` - the only entry point other modules may import.

Run `pnpm install` once after generating the module so the workspace links its
`@nestjs/common` dependency.
